
# AI Education Platform 🤖

A React-based AI education landing page designed to introduce learners to artificial intelligence courses and help them explore learning opportunities and programs.

## 🚀 Project Overview

The AI Education Platform aims to make AI learning more accessible through a modern and informative website. It presents course information, learning benefits, curriculum details and student testimonials in an organized format.

The website also includes a registration form interface for learners interested in joining a course.

## ✨ Key Features

- Modern Homepage: Attractive landing page with a clear introduction.
- Hero Section: Highlights the message "Learn AI. Build Real-World Skills."
- Course Cards: Displays available AI learning programs.
- Learning Benefits: Explains the advantages of learning AI.
- Curriculum Section: Provides an overview of course topics.
- Testimonials: Displays student feedback.
- Registration Form: Includes Name, Email, Phone and Course fields.
- Call-to-Action Buttons: Encourages visitors to explore courses and register.
- Responsive Design: Designed for different screen sizes.

## ⚙️ Installation and Setup

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:

cd ai-education-platform

3. Install dependencies:

npm install

4. Start the development server using the script configured in package.json:

npm run dev
